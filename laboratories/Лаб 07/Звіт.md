## Тема роботи
Встановлення і налаштування GitLab. Окремий цикл роботи з проєктом

## Мета роботи
Закріпити створення, клонування та оновлення проєкту у GitLab за завданням із наданого файлу.

## Завдання
Виконати завдання файлу cicd_lab6_old.pdf із папки «Лаб 7»: установити GitLab, створити й клонувати проєкт, додати файли, зробити коміт і відправити зміни на сервер.

## Теоретичні відомості
Файл у папці «Лаб 7» має заголовок «Лабораторна робота №6 Встановлення і налаштування GitLab». Цей звіт зберігає номер папки 7 і виконує наведені в ній три пункти для окремого проєкту lab07-panchyshkin.
Один GitLab-сервер може обслуговувати багато незалежних проєктів. Для кожного зберігаються власна історія, URL, права доступу та налаштування. Наявність коміту локально ще не доводить його передавання: результат перевіряється через серверну історію.

## Хід виконання
Використано реально встановлений GitLab CE 18.5.1 із лабораторної 6. Готовність сервера підтверджено станом контейнера та gitlab-ctl status. Повторне встановлення того самого сервера для другого проєкту не потрібне.
Створено інший приватний проєкт root/lab07-panchyshkin і виконано окреме клонування. Додано greeting.sh та author.txt, де вказано номер 7. Автор коміту — Панчишкін Богдан Олександрович.
Після git add і git commit виконано git push origin HEAD. Через API прочитано серверні коміти саме цього проєкту. Історію експортовано у lab07-history.bundle.

```sh
git clone http://localhost:8929/root/lab07-panchyshkin.git
cd lab07-panchyshkin
git config user.name "Панчишкін Богдан Олександрович"
# Додати greeting.sh та author.txt для роботи 7
git add .
git commit -m "Add laboratory 7 files"
git push origin HEAD
git log -2 --oneline
git bundle create ../lab07-history.bundle --all
```
