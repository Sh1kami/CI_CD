## Тема роботи
Віддалені Git-репозиторії та робота з GitHub

## Мета роботи
Навчитися працювати з віддаленим репозиторієм GitHub, гілками, pull request і перевіркою змін.

## Завдання
Створити GitHub-репозиторій, клонувати його, створити гілку, додати файли й відправити зміни. Додати xvadim як учасника та рев’ювера PR, отримати схвалення і виконати злиття в основну гілку.

## Теоретичні відомості
Віддалений репозиторій дає змогу обмінюватися комітами. clone створює локальну копію, push передає коміти на сервер, а upstream пов’язує локальну гілку з віддаленою. Pull request показує різницю між гілками та обговорення змін.
Запрошення до приватного репозиторію, запит review, схвалення та merge — різні дії. Запрошений користувач має прийняти запрошення перед призначенням рев’ювером. Схвалення виконує інша людина зі свого облікового запису.

## Хід виконання
Використано наданий репозиторій https://github.com/Sh1kami/CI_CD. На початку він не містив гілок. У main відправлено початковий README, після чого створено гілку lab04/panchyshkin-cicd і додано програмні файли лабораторних.
Зміни відправлено командою git push -u origin lab04/panchyshkin-cicd. Окремим git clone --branch перевірено клонування цієї гілки з GitHub. Створено pull request №1 до main.
Користувачеві xvadim надіслано запрошення з роллю write. Спроба requested_reviewers повернула HTTP 422, оскільки запрошення ще не прийнято. Після прийняття запрошення потрібно призначити xvadim рев’ювером, дочекатися реального APPROVED review і виконати merge.

```sh
git remote add origin https://github.com/Sh1kami/CI_CD.git
git push -u origin main
git switch -c lab04/panchyshkin-cicd
git add app.py tests lab01 lab02 scripts
git commit -m "Implement shell, CI and container laboratory tasks"
git push -u origin lab04/panchyshkin-cicd
git clone --branch lab04/panchyshkin-cicd \
  https://github.com/Sh1kami/CI_CD.git lab04/repository
# Після прийняття запрошення xvadim:
gh pr edit 1 --repo Sh1kami/CI_CD --add-reviewer xvadim
# Після фактичного схвалення:
gh pr merge 1 --repo Sh1kami/CI_CD --merge
```

Репозиторій доступний на GitHub, код відправлено в окрему гілку, PR №1 відкрито: https://github.com/Sh1kami/CI_CD/pull/1. Запрошення xvadim створено. Стан на момент підготовки звіту: очікується прийняття запрошення; схвалення PR і злиття ще не виконані.
