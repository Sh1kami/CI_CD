Панчишкін Богдан Олександрович, 3ПРс/3

## Тема роботи
Автоматизація робочих процесів за допомогою GitHub Actions

## Мета роботи
Налаштувати й перевірити робочі процеси з ручним запуском і запуском за подією push.

## Завдання
Створити у репозиторії два робочі процеси. Ручний процес виводить інформацію про операційну систему, а процес із тригером push друкує поточну системну дату.

## Теоретичні відомості
GitHub Actions читає YAML-конфігурації з .github/workflows. Ключ on визначає подію запуску, jobs описує завдання, а runs-on визначає середовище runner.
Подія workflow_dispatch дозволяє вручну обрати гілку й запустити процес. Подія push запускає інший процес автоматично після надсилання коміту. Команди виконуються на Ubuntu runner, а їхній вивід доступний у журналі запуску.

## Хід виконання
У .github/workflows створено два окремі файли. Перший читає /etc/os-release і виконує uname -a. Другий запускає date, указуючи часовий пояс у виводі.
Конфігурації додано в main. Після push GitHub запустив перевірку дати. Інформацію про ОС перевірено окремим ручним запуском для main.
Перевірено статуси завдань і команди в журналах обох запусків. Доступ до коду і секретів runner для цих команд не потрібен.

```sh
git push origin main
# Actions → ЛР5 · Інформація про ОС → Run workflow → main
```

### .github/workflows/lab05-os-info.yml

```
name: "ЛР5 · Інформація про ОС"
on:
  workflow_dispatch:
permissions: {}
jobs:
  os-info:
    runs-on: ubuntu-latest
    steps:
      - name: Вивести інформацію про ОС
        run: |
          cat /etc/os-release
          uname -a

```

### .github/workflows/lab05-system-date.yml

```
name: "ЛР5 · Системна дата при push"
on:
  push:
permissions: {}
jobs:
  system-date:
    runs-on: ubuntu-latest
    steps:
      - name: Вивести поточну системну дату й час
        run: date '+%Y-%m-%d %H:%M:%S %Z (%z)'

```

## Висновок
Два процеси реагують на різні події: workflow_dispatch виводить операційну систему, а push — дату, час і часовий пояс runner. Результати підтверджено журналами GitHub Actions.
