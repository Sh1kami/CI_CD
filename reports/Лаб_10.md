## Тема роботи
Створення власних образів. Dockerfile та оптимізація багатоетапної збірки

## Мета роботи
Навчитися проєктувати Dockerfile, фільтрувати контекст, використовувати BuildKit і багатоетапну збірку для пакування застосунку.

## Завдання
Створити .dockerignore, одноступеневий і багатоетапний Dockerfile та скрипт бенчмаркінгу. Передбачити builder, tester і production, Git-метадані, COPY --from=builder, HEALTHCHECK, Exec-форму та непривілейованого користувача.

## Теоретичні відомості
Multi-stage build відокремлює встановлення залежностей, тести та виконання. builder створює /opt/venv; tester успадковує його, додає тести й запускає unittest. production отримує лише середовище залежностей, app.py та migrate.py.
Копіювання app.py з tester змушує BuildKit виконати тестову стадію під час production-збірки. Встановлення залежностей перед COPY коду дозволяє повторно використовувати шар, коли змінюється лише програма. Cache mount зберігає кеш pip без перенесення його у фінальний образ.
ARG передає VCS_REF та BUILD_DATE, LABEL записує їх у OCI-метадані. USER 10001:10001 прибирає root-права, Exec-форма CMD забезпечує пряме отримання сигналів Python-процесом. Ідентифікатор зібраного образу незмінний, але тег можна перепризначити.

## Хід виконання
У .dockerignore виключено Git-історію, .env, журнали, кеші та сторонні навчальні підпроєкти. Для порівняння Dockerfile.single встановлює залежності, виконує тести та запускає застосунок в одному етапі.
Багатоетапний Dockerfile створює venv, встановлює зафіксовані залежності та видаляє pip із цього venv після встановлення. Базовий системний Python зберігається, а дублювання інсталятора у скопійованому середовищі усувається.
Скрипт docker_build_benchmark.sh збирає single та multi по два рази: cold означає --no-cache для інструкцій, warm — звичайну збірку з кешем. Базові образи й cache mount pip уже можуть бути локальними, тому cold не є вимірюванням повного мережевого завантаження.
Час вимірюється в цілих секундах, розмір — через docker image inspect .Size. Це по одному спостереженню на режим, без статистичного усереднення. Фактичні дані записано до evidence/benchmark.csv.

### Dockerfile.single

```
FROM python:3.12-slim
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir -r requirements.txt && python -m unittest discover -s tests -v
RUN groupadd --gid 10001 app && useradd --uid 10001 --gid app --no-create-home app
USER 10001:10001
EXPOSE 3000
HEALTHCHECK --interval=5s --timeout=4s --retries=12 CMD ["python", "-c", "import urllib.request; urllib.request.urlopen('http://127.0.0.1:3000/health', timeout=3)"]
CMD ["python", "app.py"]

```

### Dockerfile

```
# syntax=docker/dockerfile:1
FROM python:3.12-slim AS builder
WORKDIR /build
RUN python -m venv /opt/venv
ENV PATH="/opt/venv/bin:$PATH"
COPY requirements.txt .
RUN --mount=type=cache,target=/root/.cache/pip pip install -r requirements.txt && pip uninstall -y pip

FROM builder AS tester
WORKDIR /tests
COPY app.py .
COPY tests tests
RUN python -m unittest discover -s tests -v

FROM python:3.12-slim AS production
ARG VCS_REF=unknown
ARG BUILD_DATE=unknown
LABEL org.opencontainers.image.title="cicd-labs" \
      org.opencontainers.image.revision=$VCS_REF \
      org.opencontainers.image.created=$BUILD_DATE \
      org.opencontainers.image.authors="Панчишкін Богдан Олександрович 3ПРс/3"
ENV PATH="/opt/venv/bin:$PATH" PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1
RUN groupadd --gid 10001 app && useradd --uid 10001 --gid app --no-create-home app
WORKDIR /app
COPY --from=builder /opt/venv /opt/venv
COPY --from=tester /tests/app.py /app/app.py
COPY migrate.py .
USER 10001:10001
EXPOSE 3000
HEALTHCHECK --interval=5s --timeout=4s --start-period=10s --retries=12 CMD ["python", "-c", "import urllib.request; urllib.request.urlopen('http://127.0.0.1:3000/health', timeout=3)"]
CMD ["python", "app.py"]

```

### scripts/docker_build_benchmark.sh

```
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/.."
mkdir -p evidence
revision=$(git rev-parse HEAD)
built=$(date -u +%Y-%m-%dT%H:%M:%SZ)
printf 'variant,cache,seconds,bytes\n' > evidence/benchmark.csv
for variant in single multi; do
  file=Dockerfile
  [[ "$variant" != single ]] || file=Dockerfile.single
  for cache in cold warm; do
    options=()
    [[ "$cache" != cold ]] || options+=(--no-cache)
    start=$(date +%s)
    docker build "${options[@]}" -f "$file" --build-arg "VCS_REF=$revision" \
      --build-arg "BUILD_DATE=$built" -t "panchyshkin-cicd:$variant" .
    elapsed=$(( $(date +%s) - start ))
    size=$(docker image inspect "panchyshkin-cicd:$variant" --format '{{.Size}}')
    printf '%s,%s,%s,%s\n' "$variant" "$cache" "$elapsed" "$size" >> evidence/benchmark.csv
  done
done
cat evidence/benchmark.csv

```
