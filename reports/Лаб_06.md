## Теоретичні відомості
GitLab об’єднує Git-сховища, керування доступом і засоби CI/CD. На Windows сервер можна запускати у Linux-контейнері. Дані конфігурації, журнали та репозиторії зберігаються в окремих томах, тому зупинка контейнера не видаляє історію.
external_url визначає адресу сервісу й URL клонування. HTTP-порт 8929 і SSH-порт 2229 прив’язані до localhost. Приватний проєкт вимагає автентифікації; для перевірки використано тимчасовий API-токен, відкликаний після операцій.

## Хід виконання
Завантажено й запущено GitLab CE 18.5.1 у контейнері за конфігурацією lab06/compose.yaml. Налаштовано external_url http://localhost:8929 і постійні томи. Для навчального навантаження зменшено кількість процесів Puma та Sidekiq.
Після готовності сервера створено приватний проєкт root/lab06-panchyshkin з README. Репозиторій клоновано на локальну машину. Додано greeting.sh і author.txt з повним ім’ям та групою.
Налаштовано локального Git-автора, створено коміт Add laboratory 6 files і виконано git push origin HEAD. Відповідь GitLab API підтвердила наявність цього коміту на сервері. Історію збережено у lab06-history.bundle.

```sh
docker compose -f lab06/compose.yaml up -d
git clone http://localhost:8929/root/lab06-panchyshkin.git
cd lab06-panchyshkin
git config user.name "Панчишкін Богдан Олександрович"
# Додати greeting.sh і author.txt
git add greeting.sh author.txt
git commit -m "Add laboratory 6 files"
git push origin HEAD
git log -2 --oneline
```

### lab06/compose.yaml

```
name: panchyshkin-gitlab
services:
  gitlab:
    image: gitlab/gitlab-ce:18.5.1-ce.0
    hostname: localhost
    ports:
      - '127.0.0.1:8929:8929'
      - '127.0.0.1:2229:22'
    environment:
      GITLAB_OMNIBUS_CONFIG: |
        external_url 'http://localhost:8929'
        gitlab_rails['gitlab_shell_ssh_port'] = 2229
        puma['worker_processes'] = 0
        sidekiq['concurrency'] = 2
        prometheus_monitoring['enable'] = false
    shm_size: 256m
    volumes:
      - config:/etc/gitlab
      - logs:/var/log/gitlab
      - data:/var/opt/gitlab
volumes:
  config: {}
  logs: {}
  data: {}

```
