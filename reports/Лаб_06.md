## Завдання

## Теоретичні відомості
fastlane описує повторювані операції мовою Ruby у файлі Fastfile. Іменована lane об’єднує кроки, а Appfile містить ідентифікатор пакета. Gemfile фіксує версію fastlane, Gemfile.lock — конкретний набір Ruby-залежностей.
Android versionCode — ціле число, яке збільшується для нової збірки; versionName — назва версії для користувача. У проєкті обидва значення зберігаються у version.properties та читаються Gradle. assembleRelease формує release APK; підпис для публікації потребує окремого keystore.

## Хід виконання
Створено мінімальний Android-застосунок ua.edu.kntu.panchyshkin.cicdlab з Java Activity, яка відображає предмет, ім’я студента й групу. Використано Android Gradle Plugin 8.7.3, Gradle 8.9, JDK 17, compileSdk/targetSdk 35 та minSdk 23.
Для незалежності від локальної інсталяції Android Studio підготовлено Docker-оточення з Ruby 3.3, Android SDK і fastlane 2.226.0. Команда bundle install встановила fastlane; наявність Fastfile та Appfile активує його для проєкту.
Lane bump змінила versionCode з 2 на 3. Lane greeting передала тестові ім’я й вік у сценарій лабораторної 1. Lane release викликала clean assembleRelease через Gradle. Кожну lane виконано в контейнері з робочим каталогом lab06.

```
    namespace 'ua.edu.kntu.panchyshkin.cicdlab'
    compileSdk 35

        applicationId 'ua.edu.kntu.panchyshkin.cicdlab'

        versionName versionProps['versionName']

}

```

### lab06/fastlane/Appfile

```
package_name("ua.edu.kntu.panchyshkin.cicdlab")

```

### lab06/fastlane/Fastfile

```
require 'shellwords'
default_platform(:android)
platform :android do
  desc 'Increment Android version code'
  lane :bump do
    file = File.expand_path('../version.properties', __dir__)
    content = File.read(file)
    version_line = /^versionCode=(\d+)(?=\r?$)/
    match = content.match(version_line)
    UI.user_error!("versionCode is missing from #{file}") unless match
    old = match[1].to_i
    File.write(file, content.sub(version_line, "versionCode=#{old + 1}"))
    UI.success("versionCode #{old} -> #{old + 1}")
  end
  desc 'Run the shell script from laboratory 1'
  lane :greeting do
    script = File.expand_path('../../lab01/greeting.sh', __dir__)
    sh("printf 'Богдан\\n20\\n' | sh #{Shellwords.escape(script)}")
  end
  desc 'Create an unsigned release APK'
  lane :release do
    gradle(task: 'clean assembleRelease', gradle_path: '/opt/gradle/bin/gradle', project_dir: File.expand_path('..', __dir__))
  end
end

```

## Результати виконання
У журналі bump зафіксовано versionCode 2 → 3. Lane greeting вивела «Привіт Богдан, через рік тобі буде 21 років!». Release-збірка завершилася повідомленням BUILD SUCCESSFUL. Усі три процеси повернули код 0.
Створено app-release-unsigned.apk. Це фактичний release-артефакт без цифрового підпису. Він придатний для подальшого підписання власним ключем; публікація до Google Play у цій роботі не виконувалася.
