## Мета роботи
Ознайомитися з командними оболонками Unix-систем і навчитися використовувати мову sh для розроблення сценаріїв.

## Завдання
Розробити sh-скрипт, який запитує ім’я та вік користувача і виводить повідомлення «Привіт _name_, через рік тобі буде _age_ років!». Вік у повідомленні має бути збільшений на один.

## Теоретичні відомості
Командна оболонка виконує команди та сценарії з текстових файлів. Рядок #!/bin/sh задає інтерпретатор. Команда read зчитує рядок зі стандартного вводу, printf форматує вивід, а вираз $((age + 1)) виконує цілочислове додавання.
IFS= перед read зберігає пробіли в імені. Параметр -r забороняє спеціальне трактування зворотної скісної риски. Подвійні лапки навколо змінних захищають значення від поділу на слова. Код завершення 0 означає успіх, 1 — помилку введення.

## Хід виконання
Створено файл lab01/greeting.sh у UTF-8 із завершеннями рядків LF. Сценарій спочатку перевіряє ім’я, потім приймає лише десяткові цифри віку. Початкові нулі видаляються, щоб значення 008 не трактувалося як вісімкове число.
Вік обмежено діапазоном 0–150. Перевірка довжини до арифметичної операції відхиляє надто велике число та запобігає переповненню. Після перевірок обчислюється вік через рік. Помилки записуються у stderr.
Синтаксис перевірено командою bash -n lab01/greeting.sh. Реальні запуски виконано GNU Bash із Git for Windows у POSIX-режимі. Українське ім’я та багаторядкове введення передавалися через stdin.

### lab01/greeting.sh

```
#!/bin/sh
printf '%s\n' 'Введіть ім’я:'
if ! IFS= read -r name || [ -z "$name" ]; then
    printf '%s\n' 'Помилка: ім’я не може бути порожнім.' >&2
    exit 1
fi
printf '%s\n' 'Введіть вік:'
IFS= read -r age || exit 1
case "$age" in
    ''|*[!0-9]*) printf '%s\n' 'Помилка: вік має бути невід’ємним цілим.' >&2; exit 1 ;;
esac
while [ "${age#0}" != "$age" ]; do age=${age#0}; done
[ -n "$age" ] || age=0
if [ "${#age}" -gt 3 ] || [ "$age" -gt 150 ]; then
    printf '%s\n' 'Помилка: допустимий вік від 0 до 150.' >&2
    exit 1
fi
printf 'Привіт %s, через рік тобі буде %s років!\n' "$name" "$((age + 1))"

```

## Результати виконання
Коректне введення «Богдан», 20 дало значення 21 і код завершення 0. Для віку 0 отримано 1, для 008 — 9. Нечисловий вік abc, порожнє ім’я та надмірно велике число відхилено з кодом 1. Нижче наведено витяги з фактичних журналів запуску.
