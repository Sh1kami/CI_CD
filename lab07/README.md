# Лабораторна 7
У наданій папці «Лаб 7» міститься cicd_lab6_old.pdf із заголовком
«Лабораторна робота №6 Встановлення і налаштування GitLab».
Тому виконано повторний цикл роботи з окремим GitLab-проєктом lab07.
Команда запуску сервера з кореня репозиторію:
`docker compose -f lab07/gitlab-setup/compose.yaml up -d`.
Сервер відкривається за адресою http://localhost:8929. Історія проєкту роботи 7 міститься в `lab07-history.bundle`.
